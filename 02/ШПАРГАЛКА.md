### Пример программы

> Логическая функция F задаётся логическим выражением *y &and; (x &or; z) &or; &not;(y &or; z) &or; w*. На рисунке приведён частично заполненный фрагмент таблицы истинности функции F, содержащий неповторяющиеся строки. Определите, какому столбцу таблицы истинности соответствует каждая из переменных w, x, y, z.

```python
print('w x y z')
for w in range(2):
    for x in range(2):
        for y in range(2):
            for z in range(2):
                if (y and (x or z) or (not (y or z)) or w) == 0:
                    print(x, y, z, w)
```

### Эквиваленты записи логических операций в математике и в Python

| Математическая запись | Запись в Python |
| --------------------- | --------------- |
| &not;A                | `not A`         |
| A &and; B             | A and B         |
| A &or; B              | A or B          |
| A&nbsp;&rarr;&nbsp;B  | A <= B          |
| A &equiv; B           | A == B          |
