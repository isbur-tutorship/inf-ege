Про изображение 2х2

Там интересная история получилось.

Во-первых, оказывается, никакого альфа-канала, на который я грешил, нет — используется честное 24-битное кодирование, по 3 байта на каждый пиксель.

НО.

И это во-вторых.

Оказывается, пиксели группируются по строкам изображения, и каждая строка добивается незначащими нулями до кратного восьмёрке числа байт. Или, по крайней мере, в случае с двумя пикселями по 3 байта их общая сумма — шесть — дополняется двумя незначащими байтами до восьми.

UPD от ЧатаГПТ: да, паддинг был принятой практикой во времена разработки стандарта, и, если точно, добивка происходит до кратности 4. Сейчас в этом нужды для прикладных программистов нет, так как на уровне архитектуры процессора такие операции реализованы и оптимизированы в автоматическом режиме.
