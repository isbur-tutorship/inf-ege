Простейший пример

Сколько единиц содержится в двоичной записи значения выражения:

$$ 4^{2020} + 2^{2017} – 15? $$

Программа на Python:

n = 4**2020 + 2**2017 - 15
n = bin(n)[2:]
print(n.count("1"))

Примеры самописных функций перевода:

# 10 -> 13

def encode(x):
    digits = "0123456789abc"
    return digits[x]

def f(x):
    if x < 13:
        return encode(x)
    else:
        return f(x // 13) + encode(x % 13)

print(f(2024))

# 10 -> 6

def g(x):
    if x < 6:
        return str(x)
    else:
        return g(x // 6) + str(x % 6)

print(g(2024))

# 10 -> 7

def h(x):
    s = ""
    while x > 0:
        s = str(x % 7) + s
        x //= 7
    return s

print(h(2024))

Зачастую полный перевод в n-ричную систему счисления не нужен, достаточно лишь подсчитывать или суммировать отдельные числа. См. пример:

(kompege-вариант-25194722)

Здесь нам понадобится самописный перевод в 11-ричную систем счисления без сохранения цифр, а только с подсчётом нулей:

for x in range(1, 3001):
	N = 9*11**210 + 8*11**150 - x
	c = 0
	while N > 0:
		if N % 11 == 0:
			c += 1
		N //= 11
	if c == 60:
		print(x)

Строки здесь не работают, так как у нас есть цифры со значением больше 9. Это можно исправить самописной функцией encode(), но мы лучше воспользуемся списками.

for x in range(1, 3001):
    N = 9*11**210 + 8*11**150 - x
    m = []
    while N > 0:
        m.append(N % 11)    # Не забываем, что число записано в обратном порядке.
                            # В этой задаче это не критично, но может быть критично в пятом, к примеру
        N //= 11
    if m.count(0) == 60:
        print(x)
