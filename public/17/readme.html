Возможные условия, налагаемые на числа

  • Четырёхзначность (и аналогично дву-. трёх- и т.д. -значность):
1000 <= abs(x) <= 9999
999 < abs(x) < 10000
  • Кратность (она же делимость) на число 17 (или на любое другое натуральное число):
# Общепринятый способ:
x % 17 == 0
# Иллюстративный (плохой в бою) способ:
x // 17 == x / 17
  • Окончание на определённый набор цифр (например, на “123”, т.е. подходят 4123, 65123, и не подходят 4205, 36, 67125):
# Сколько цифр, на такую степень десятки мы и делим:
abs(x) % 1000 == 123
# То же:
abs(x) % 10**3 == 123
  • Число начинается на определённый набор цифр (например, на те же “123”)
# Извлечение символов по одному
str(x)[0] == "1" and str(x)[1] == "2" and str(x)[2] == "3"
# Срез
str(x)[:2] == "123"
# или str(x)[0:2] = "123"
# Значения слева и справа от двоеточия работают как аргументы функции range(), если оба указаны.
# Если пропущено левое значение, то по умолчанию подставляется 0
# Если пропущено правое значение, то подставляется len(str(x))
# Помним, что в функции range левое значение включается, правое исключается
# В принципе, как и функция range, срезы могут принимать до трёх аргументов

Перебор пар (троек) последовательных значений

Пример

Элементы ряда могут принимать целые значения в диапазоне [−10000; 10000]. Определите количество троек элементов последовательности, в которой только одно число трехзначное, а сумма тройки меньше наибольшего числа, оканчивающегося на 17. В данной задаче под тройкой подразумевается три идущих подряд элемента последовательности.

Решение образца 2026 года:

A = [int(x) for x in open("1_17.txt")]

max17 = max([x for x in A if abs(x) % 100 == 17])

k = 0
for a,b,c in zip(A, A[1:], A[2:]):
	c3 = (99 < a < 1000) + (99 < b < 1000) + (99 < c < 1000)
	if c3 == 1 and a+b+c < max17:
		k += 1
		
print(k)

Старое решение:

# Чтение файла
f = open("17.txt")
A = f.readlines()
A = [int(x) for x in A]

# Поиск наибольшего числа в последовательности, оканчивающегося на 17
max17 = -10001
for x in A:
    if abs(x) % 100 == 17 and x > max17:
        max17 = x

# Собственно решение задачи
counter = 0
for i in range(len(A) - 2):
    # Пример техники работы с последовательными тройками
    B = []
    for j in range(3):
        B.append(A[i+j])
    C = []
    for j in range(3):
        C.append(len(str(abs(B[j]))))
    if C.count(3) == 1 and sum(B) < max17:
        counter += 1

print(counter)

Перебор всех возможных пар

Чтобы перебрать все пары различных элементов, можно использовать двойной вложенный цикл, например, так:

max_s = 0
k = 0
for i in range(len(A)):
    for j in range(len(A)):
        s = A[i]+A[j]
        if s % 9 == 0:
            k += 1
            if s > max_s:
                max_s = s

Данная программа, при условии, что можно брать любые два элемента последовательности, а не только идущие друг за другом, считает количество пар элементов, сумма которых делится на 9 (переменная k), а также находит максимальную из таких сумм (переменная max_s).

Small tip

Остаток от деления отрицательного числа — это дополнение этого числа до делителя, например:

>>> -117 % 100
83

Поэтому чтобы не получать неожиданных результатов от операций взятия остатка, надо брать остаток от модуля (abs(n)) от этого числа.
